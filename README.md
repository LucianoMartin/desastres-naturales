# AlertApp

Aplicación para avisar sobre posibles desastres naturales en una zona.

## Descripción

El objetivo de este proyecto es desarrollar una aplicación móvil que permita informar y alertar a los usuarios sobre posibles desastres naturales en su área.

## Como ejecutar

1. Instalar Visual Studio Code y Git.

2. Abrir Visual Studio Code.

3. Instalar la extensión Flutter y Dart desde la sección de extensiones.

4. Abrir la paleta de comandos tocando en el buscador de arriba o con `Ctrl + Shift + P`.

5. Buscar y seleccionar Flutter: New Project.

6. Cuando solicite la ubicación del SDK, seleccionar Download SDK.

7. Elegir una carpeta donde instalar Flutter, por ejemplo `C:\src\flutter`.

8. Esperar a que finalice la descarga y seleccionar Add SDK to `PATH`.

9. Cerrrar Visual Studio Code.

10. Abrir Visual Studio Code en la carpeta de origen.

11. Abrir una terminal nueva desde la barra superior o con `Ctrl + Shift + Ñ`.

12. Ejecutar el comando `flutter pub get` para instalar dependencias.

13. Ejecutar el comando `flutter run` para correr la aplicación.

14. Seleccionar la plataforma para correr la aplicación, para mas comodidad la opción `2` abre una pestaña de Chrome.

15. (Opcional) Para compilar una versión instalable de Android, ejecutar `flutter build apk`. El archivo generado se encontrará normalmente en `build/app/outputs/flutter-apk/app-release.apk`.

## Tecnologías utilizadas

- Flutter: desarrollo de la aplicación móvil.

- Dart: lenguaje de programación.

- Firebase Authentication: autenticación y gestión de usuarios.

- Cloud Firestore: almacenamiento y consulta de datos, si corresponde a la configuración del proyecto.

- OpenStreetMap / flutter_map: visualización de mapas, según la implementación actual.
